These static DM Sans instances come from the variable font bundled with the
Blueprint prototype in `prototypes/menu-ui/assets/dm-sans.ttf`:

- `dm-sans-medium.ttf`: weight 500, optical size 14, for interface headings.
- `dm-sans-display.ttf`: weight 500, optical size 40, for the wordmark and large headings.

They were instantiated using fontTools `varLib.instancer`; no outlines were
redrawn. The SIL Open Font License and copyright notice are in `OFL-DMSans.txt`.
The interface also uses the original IBM Plex Mono font and license in the
prototype assets directory.
